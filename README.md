# 学院就业信息查询工具

一个轻量的网页工具：学生在搜索框输入企业名称，即可查到该企业相关的微信招聘推文链接。
作为「学生」和「企业招聘链接」之间的中转站。

- 纯前端，无需服务器、无需数据库
- 完全免费（GitHub Pages 托管）
- 维护简单：新增链接 = 在一个文件里加几行

---

## 一、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 网页本体，含搜索、筛选、展示功能。一般不用改。 |
| `data.json` | **链接数据库**。日常维护只改这个文件。 |
| `README.md` | 本说明文档。 |

## 二、老师如何新增招聘链接（最常用）

打开 `data.json`，在 `jobs` 列表里照着格式加一条记录即可。

```json
{
  "updatedAt": "2026-09-22",
  "jobs": [
    {
      "company": "国家电网有限公司",
      "title": "国家电网2027年高校毕业生招聘公告（第一批）",
      "date": "2026-09-18",
      "category": "国企招聘",
      "url": "https://mp.weixin.qq.com/s/xxxxxxxxxxxx"
    }
  ]
}
```

每条记录的字段含义：

| 字段 | 含义 | 是否必填 |
| --- | --- | --- |
| `company` | 企业名称（学生按这个搜索） | 必填 |
| `title` | 推文标题 | 建议填 |
| `date` | 发布日期，格式 `年-月-日` | 建议填 |
| `category` | 岗位类别，会自动生成筛选按钮。**支持多个标签**：单个直接写 `"国企招聘"`；多个用数组写 `["国企招聘", "技术岗"]` | 可选 |
| `url` | 微信推文链接 | 必填 |

**新增技巧：**
- 每条记录用 `{ }` 包起来，记录之间用英文逗号 `,` 隔开，最后一条后面不要加逗号。
- 改完后把最上面的 `updatedAt` 更新成当天日期，网页会显示「最近更新」。
- 所有标点（引号、逗号、冒号）都要用**英文半角**，这是 JSON 的要求。

> 小提示：可以把 `data.json` 内容粘到 https://www.json.cn 校验一下格式，避免出错。

## 三、如何发布上线（一次性设置，之后一劳永逸）

推荐用 **GitHub Pages**，免费且更新方便。

1. 注册一个 GitHub 账号：https://github.com
2. 新建一个仓库（Repository），例如命名 `job-links`，设为 Public。
3. 把本文件夹里的 `index.html`、`data.json` 上传到仓库
   （网页端可直接拖拽上传，或用 GitHub Desktop 客户端）。
4. 进入仓库的 **Settings → Pages**，
   在 **Branch** 处选择 `main` 分支、`/ (root)` 目录，点 Save。
5. 稍等一两分钟，页面会给出一个网址，形如：
   `https://你的用户名.github.io/job-links/`
6. 把这个网址发到就业信息群，每位同学点开即可使用。

**以后更新链接：** 只需在 GitHub 上编辑 `data.json` 并保存（Commit），
网页会自动更新，学生刷新即可看到最新内容。

## 四、本地预览（改完先自己看看效果）

因为浏览器安全限制，**直接双击 `index.html` 可能读不到 `data.json`**。
需要用一个本地小服务器预览，任选一种：

**方式 A：用 Python（电脑一般自带）**
在本文件夹里打开终端，运行：
```
python -m http.server 8000
```
然后浏览器打开 http://localhost:8000

**方式 B：用 VS Code**
安装扩展 **Live Server**，右键 `index.html` → “Open with Live Server”。
